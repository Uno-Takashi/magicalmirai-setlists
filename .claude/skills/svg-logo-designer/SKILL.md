# SVG ロゴデザイナー

設計要件から、拡大縮小しても劣化しないプロ品質の SVG ロゴを作り、複数の案とレイアウトを提示するスキル。

## このスキルを使うとき

次のような依頼を受けたときに使う。

- 説明や仕様からロゴを作る
- ブランドアイデンティティやビジュアルマークを設計する
- ロゴのバリエーションや案を出す
- アイコンやシンボルを作る
- ワードマークやレターマークを作る
- ブランディング用の拡大縮小可能な画像を作る
- レイアウトやスタイル違いのロゴを書き出す

## 基本の流れ

### フェーズ 1: 要件の把握

ロゴの依頼を受けたら、まず設計に必要な情報を集める。

1. **ブランドの情報**
   - 会社名・製品名
   - 業種と市場
   - 想定する利用者
   - ブランドの人格 (モダン / クラシック / 遊び心 / 硬派 など)
   - ブランドの価値観と伝えたいこと
   - 競合 (差別化のため)

2. **デザインの好み**
   - ロゴの種類:
     - **ワードマーク**: 文字だけで組む (Google、Coca-Cola のような形)
     - **レターマーク**: 頭文字・略称 (IBM、HBO のような形)
     - **ピクトリアルマーク**: 具象のアイコン・シンボル (Apple、Twitter のような形)
     - **アブストラクトマーク**: 抽象的な幾何形 (Pepsi、Adidas のような形)
     - **マスコット**: キャラクター (KFC のカーネル、ミシュランマンのような形)
     - **コンビネーションマーク**: アイコン + 文字 (Burger King、Lacoste のような形)
     - **エンブレム**: シンボルの中に文字を収める (Starbucks、Harley-Davidson のような形)

3. **スタイルの指針**
   - カラーパレット (指定を受ける、または提案する)
   - 色が与える印象の検討
   - フォントの好み (文字を使う場合)
   - 視覚的なスタイル:
     - ミニマル
     - 幾何学的
     - 有機的 / 流れるような
     - 力強い
     - 上品 / 洗練
     - 親しみやすい / 遊び心
     - テック / モダン
     - ヴィンテージ / レトロ

4. **技術的な要件**
   - 大きさの制約 (小さく使うのか、大きく使うのか)
   - 使う場面 (Web サイト、印刷物、グッズ など)
   - カラー版とモノクロ版のどちらが要るか
   - 背景 (明るい / 暗い / 透過)
   - 拡大縮小の要件

5. **バリエーションの数**
   - コンセプトはいくつか (3〜5 案を勧める)
   - 1 案あたりのレイアウトはいくつか (横組み / 縦組み / 正方形 / 円形)
   - 配色違いは要るか

### フェーズ 2: コンセプトの立案

要件をもとに複数のロゴ案を作る。

#### 案 1: 本命の方向性

主軸となる方向を作り込む。

**考えかた:**

- ブランドに結びつく視覚的な比喩を探す
- 余白 (ネガティブスペース) を活かせないか検討する
- 記憶に残るか、他と被らないかを確かめる
- 単純さと個性のつり合いを取る
- 文化的に問題のない表現かを確かめる

**SVG の構造:**

```xml
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 200 200" width="200" height="200">
  <defs>
    <!-- グラデーション、パターン、フィルタ -->
    <linearGradient id="gradient1" x1="0%" y1="0%" x2="100%" y2="100%">
      <stop offset="0%" style="stop-color:#4F46E5;stop-opacity:1" />
      <stop offset="100%" style="stop-color:#7C3AED;stop-opacity:1" />
    </linearGradient>
  </defs>

  <!-- ロゴの要素 -->
  <g id="logo-symbol">
    <!-- シンボル / アイコン -->
  </g>

  <g id="logo-text">
    <!-- 文字 (使う場合) -->
  </g>
</svg>
```

#### 案 2〜5: 別の方向性

異なる切り口を探るバリエーションを作る。

- 別の視覚的な比喩
- 別のスタイルの当てかた
- 別のレイアウトと構成
- 別の配色の当てかた

### フェーズ 3: レイアウトのバリエーション

各案について、複数のレイアウトを用意する。

#### レイアウト A: 横組み

- 左にアイコン、右に文字
- Web サイトのヘッダー、名刺に向く
- 横長の比率

#### レイアウト B: 縦組み

- 上にアイコン、下に文字
- SNS のプロフィール、アプリアイコンに向く
- 縦長の比率

#### レイアウト C: 正方形 / 中央揃え

- アイコンと文字を中央に置く
- ファビコン、アプリアイコン、プロフィール画像に向く
- 1:1 の比率

#### レイアウト D: アイコンのみ

- 文字なしのシンボル
- 小さい表示、透かしに向く
- 小さくても判別できる形

#### レイアウト E: 文字のみ

- アイコンなしのワードマーク
- 最小限の使いかたに向く
- タイポグラフィが主役

### フェーズ 4: SVG の生成

読みやすく最適化された SVG を書く。

**守ること:**

1. **意味の通る、整理されたコード**

```xml
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 200 60">
  <!-- グループで役割ごとにまとめる -->
  <g id="icon">
    <!-- アイコンの要素 -->
  </g>
  <g id="wordmark">
    <!-- 文字の要素 -->
  </g>
</svg>
```

2. **拡大縮小に耐える設計**
   - `viewBox` で伸縮できるようにする
   - ピクセル固定の寸法を避ける
   - 相対的な単位を使う
   - 複数のサイズで見え方を確かめる

3. **色の管理**

```xml
<!-- 色は一度定義して使い回す -->
<defs>
  <style>
    .primary { fill: #4F46E5; }
    .secondary { fill: #10B981; }
    .text { fill: #1F2937; }
  </style>
</defs>

<rect class="primary" x="0" y="0" width="100" height="100" />
```

4. **最適化**
   - 不要な属性を消す
   - まとめられるパスはまとめる
   - 繰り返す要素は `symbol` にする
   - 小数の桁数を減らす
   - 見えない要素を消す

5. **アクセシビリティ**

```xml
<svg role="img" aria-labelledby="logo-title logo-desc">
  <title id="logo-title">会社名のロゴ</title>
  <desc id="logo-desc">青い円形のアイコンと会社名の組み合わせ</desc>
  <!-- ロゴの中身 -->
</svg>
```

### フェーズ 7: 利用ガイドライン

使いかたの説明を添える。

````markdown
# ロゴ利用ガイドライン

## 提供する形式

### SVG (ベクター画像)

- **用途:** Web サイト、デジタル用途、大判印刷
- **利点:** どこまでも拡大できる、ファイルが小さい、編集できる
- **使いかた:** HTML に直接埋め込むか、デザインツールで開く

### PNG への書き出し

PNG が必要なときは次のいずれかで変換する。

**方法 1: Inkscape (無料)**

```bash
inkscape logo.svg --export-png=logo.png --export-width=1000
```

**方法 2: ImageMagick**

```bash
convert -background none logo.svg logo.png
```

**方法 3: オンライン変換**

- https://cloudconvert.com/svg-to-png
- SVG をアップロードして PNG をダウンロードする

## 余白 (アイソレーション)

ロゴのまわりには最小限の余白を確保する。

- 余白の幅 = ロゴのシンボルの高さ
- 余白の中に文字や図を置かない

## 最小サイズ

- **デジタル:** 幅 100px 以上
- **印刷:** 幅 1 インチ以上

## 色の使いかた

### 基本のパレット

- 白・明るい背景ではフルカラー版
- 暗い背景では白のモノクロ版
- 明るい背景では濃色のモノクロ版

### 場面ごとの使い分け

**Web サイトのヘッダー:**

- フルカラー版が基本
- 背景とのコントラスト比 4.5:1 を確保する

**SNS:**

- 正方形 / 円形の切り抜きを使う
- 必要なら背景色を敷く

**印刷物:**

- カラー印刷ではフルカラー版
- 白黒印刷では黒のモノクロ版
- 特色印刷はコストを抑えられるので検討する

## してはいけないこと

❌ 次のことはしない。

- ロゴを引き伸ばす、歪める
- 決められたパレット外の色に変える
- 効果 (影、光彩 など) を足す
- 回転させる、傾ける
- 余白を取らずに情報量の多い背景に置く
- ロゴの要素を作り直す、書き換える

## ファイルの構成

```text
logos/
  concept-1/
    horizontal/
      full-color.svg
      monochrome-dark.svg
      monochrome-light.svg
    vertical/
      [同じバリエーション]
    icon/
      [同じバリエーション]
  concept-2/
    [同じ構成]
```

## 技術的な仕様

### Web での使いかた

```html
<!-- インライン SVG (細かく制御したいとき) -->
<svg><!-- SVG のコード --></svg>

<!-- img タグ (手軽) -->
<img src="logo.svg" alt="会社名のロゴ" />
```

```css
/* CSS の背景 */
.logo {
  background-image: url('logo.svg');
  background-size: contain;
}
```

### 画面幅への対応

```css
.logo {
  width: 100%;
  max-width: 200px;
  height: auto;
}

/* モバイル */
@media (max-width: 768px) {
  .logo {
    max-width: 150px;
  }
}
```
````

## パターンと作例

### ワードマーク

```xml
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 300 80">
  <defs>
    <style>
      .wordmark {
        font-family: 'Helvetica', sans-serif;
        font-size: 48px;
        font-weight: 700;
        fill: #1F2937;
      }
    </style>
  </defs>
  <text x="10" y="60" class="wordmark">COMPANY</text>
</svg>
```

### 幾何学的なアイコン

```xml
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 100 100">
  <defs>
    <linearGradient id="grad" x1="0%" y1="0%" x2="100%" y2="100%">
      <stop offset="0%" style="stop-color:#4F46E5" />
      <stop offset="100%" style="stop-color:#7C3AED" />
    </linearGradient>
  </defs>

  <!-- 六角形 -->
  <polygon
    points="50,5 95,27.5 95,72.5 50,95 5,72.5 5,27.5"
    fill="url(#grad)"
    stroke="#312E81"
    stroke-width="2"
  />

  <!-- 内側の要素 -->
  <circle cx="50" cy="50" r="20" fill="#FFFFFF" />
</svg>
```

### アブストラクトマーク

```xml
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 100 100">
  <!-- 流れるような抽象形 -->
  <path
    d="M10,50 Q30,20 50,50 T90,50 Q70,80 50,50 T10,50 Z"
    fill="#10B981"
    opacity="0.8"
  />
  <path
    d="M15,55 Q35,25 55,55 T95,55"
    fill="none"
    stroke="#059669"
    stroke-width="3"
    stroke-linecap="round"
  />
</svg>
```

### コンビネーションマーク

```xml
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 200 80">
  <!-- アイコン -->
  <g id="icon">
    <circle cx="40" cy="40" r="30" fill="#4F46E5" />
    <path d="M30,35 L35,45 L50,25" stroke="#FFFFFF" stroke-width="3" fill="none" stroke-linecap="round" stroke-linejoin="round" />
  </g>

  <!-- 文字 -->
  <g id="text">
    <text x="85" y="45" font-family="Arial, sans-serif" font-size="28" font-weight="700" fill="#1F2937">
      COMPANY
    </text>
  </g>
</svg>
```

## 反復のしかた

最初の案を出したあとは次の順で進める。

1. **意見をもらう**
   - どの案がいちばん響いたか
   - 残したい要素、変えたい要素はどれか
   - 気になる点はあるか

2. **選ばれた案を詰める**
   - 必要なら配色を直す
   - 比率を調整する
   - 細部を仕上げる
   - いろいろな大きさで確かめる

3. **最終バリエーションを作る**
   - すべてのレイアウト
   - すべての配色
   - 特殊な用途の分

4. **一式を渡す**
   - SVG ファイル一式
   - 利用ガイドライン
   - 技術仕様
   - 書き出し手順

## 進めかた

依頼者とのやりとりでは次を意識する。

1. **ブランドを理解する**
   - ブランドの人格を聞く
   - 想定する利用者を把握する
   - 業種の文脈を調べる

2. **設計の理由を説明する**
   - 視覚的な比喩の意図を伝える
   - 色の選択理由を伝える
   - 構成の判断を説明する

3. **選択肢を出す**
   - 複数の案を出す
   - レイアウト違いを見せる
   - 配色違いを見せる

4. **柔軟でいる**
   - 指摘を素直に受け取る
   - もらった意見で作り直す
   - できないことは理由とともに伝える

5. **伝える**
   - SVG の利点を説明する
   - 正しい使いかたを案内する
   - 実務上の勘所を共有する

## 成果物

一式そろえて渡す。

1. **SVG ファイル**
   - すべての案 (3〜5)
   - 案ごとのレイアウト (3〜5)
   - 配色のバリエーション (3〜4)
   - 合計でおおむね 30〜75 ファイル

2. **ドキュメント**
   - 利用ガイドライン
   - 色の指定
   - 推奨サイズ
   - してよいこと / いけないこと

3. **技術情報**
   - ファイル構成
   - SVG から PNG への書き出し手順
   - Web への組み込み例
   - 印刷用の仕様

4. **任意: モックアップ**
   - 名刺に載せた例
   - Web サイトのヘッダーに載せた例
   - 製品に載せた例
   - 看板に載せた例

## 進行例

**依頼:**

> テックスタートアップ「CloudSync」のロゴを作ってほしい。クラウドストレージのサービスで、モダンで信頼できる雰囲気にしたい。

**返しかた:**

1. **確認する:**
   - 「CloudSync 向けにモダンでテック寄りのロゴを作ります。いくつか確認させてください。
     - 希望の色はありますか (信頼感なら青を提案しますが、こちらでパレットを組むこともできます)
     - ロゴの種類の希望はありますか (アイコン + 文字のコンビネーションマークを想定しています)
     - 入れたい / 避けたいモチーフはありますか (雲、同期の矢印 など)
     - 案はいくつ見たいですか (3〜4 案を勧めます)」

2. **案を作る:**
   - **案 1**: 抽象化した雲と同期の矢印、幾何学的でモダン
   - **案 2**: 雲を織り込んだ「C」のミニマルなワードマーク
   - **案 3**: 雲とノードを収めた円形のバッジ
   - **案 4**: 雲と一体化した太い「CS」のレターマーク

3. **バリエーションを作る:**
   - 各案について横組み / 縦組み / アイコンのみ
   - 配色はフルカラー / モノクロ / 反転

4. **提示する:**
   - 全案を設計意図とともに見せる
   - 各案の SVG コードを添える
   - 利用ガイドラインを付ける
   - 意見をもとに作り直すことを伝える

5. **仕上げる:**
   - 依頼者が案を選ぶ
   - 求められた調整を反映する
   - 全バリエーションを確定する
   - 一式にまとめて渡す

よいロゴは、単純で、記憶に残り、古びず、どこでも使えて、ブランドに合っている。あらゆる場面で機能し、長く使える形を目指す。
